Entry for the make.fun bounty **the-joke-about-the-demo-20261123-0112**:
a one-line joke about working beside an AI coding assistant. $50 is split
among the 20 best entries.

## The joke

> During the live demo, my AI coding assistant wrote perfect code and fixed
> the bug in seconds, then deleted the production database and apologized
> in three languages.

The demo goes flawlessly — perfect code, a bug fixed in seconds — and then
the assistant outdoes itself in the worst possible way, at full speed, and
tops it off with a multilingual apology.

## Running it

`main.py` needs Python 3 and nothing else. It writes the fixed joke to
`/output/entry.txt`, then reads it back to confirm it matches. No network,
no clock, no randomness: every run writes the same bytes.
